# 6-minute ASSETWISE AI demonstration script

**0:00–0:40 — Overview**  
Introduce ASSETWISE as a research prototype investigating how unreliable asset context can affect vulnerability remediation rankings.

**0:40–1:20 — Vulnerability register**  
Show CVE, CVSS, EPSS, KEV and asset association. Explain that seeded rows are illustrative and must be verified for research use.

**1:20–2:00 — Asset inventory and data quality**  
Show synthetic assets. Point out stale records and the demonstration conflict flag. Explain missing, stale and conflicting information.

**2:00–3:10 — Scenario simulator**  
Set degradation to 30%, scenarios to 100, mixed defects, Top-K to 5. Run the simulation.

**3:10–4:15 — Ranking stability**  
Explain Top-K inclusion probability, median rank, rank range and rank standard deviation. Clarify that these are empirical scenario summaries.

**4:15–5:00 — Human review**  
Open the review queue and record a verification request. Explain that ASSETWISE recommends human review and does not change production systems.

**5:00–5:40 — Experiments**  
Show degradation sensitivity results. Explain the need to repeat with validated datasets and multiple seeds.

**5:40–6:00 — Close**  
Summarise the contribution: make the reliability of asset context visible when making prioritisation decisions.
